# 常見問題

**任何人都可以使用嗎？**

本專案可公開下載、使用與修改，沒有綁定原作者的路徑、帳戶或品牌。但完整流程需要可載入 skill 的 Agent、影片存取能力、本機 CapCut 與電腦控制工具。並非每個聊天環境都具備這些能力。

**需要付費嗎？**

Skill 採 MIT 授權。本專案不收取使用費；你使用的 AI、圖片服務或 CapCut 功能可能另有費用，按各服務方案而定。

**支援 Windows 嗎？**

指令與 Python 腳本沒有固定 macOS 路徑。Windows 可在具備 Python、FFmpeg 和相應 Agent 能力時嘗試；目前未完成 Windows CapCut 端到端驗證，不能保證每個介面版本都適用。

**支援 ChatCut 嗎？**

這個流程針對 CapCut。ChatCut 是另一個產品，不會自動替換。

**我只有 MP4，沒有 CapCut 原專案？**

可以先分析，亦可按工具能力建立新專案、剪接和加入少量文字。已燒錄字幕、特效和背景無法當成獨立原生圖層自由修改；Agent 應解釋可行範圍。

**沒有聲音或字幕會失敗嗎？**

沒有音訊時可用畫面分析；有燒錄字幕就直接讀。沒有足夠語言證據時，不會捏造口播內容。若片長短於五秒，會分析實際可用片段。

**會複製我的聲音嗎？**

不會默默這樣做。新口播需要補錄，或使用你已授權的語音流程。能用現有語音完成的剪法會優先考慮。

**Hook Score 是 Instagram 官方評分嗎？**

不是。它是 AI 內容判斷。Likely Retention Risk 也是結構預測，不能寫成觀眾真的在某秒流失；成效需用發佈後的真實 Insights 驗證。

**安全區是否 Instagram 官方固定規格？**

優先用你提供的指南。沒有指南時採保守工作範圍並明確標示假設。Reels 介面、封面及個人頁裁切並非同一回事；需要依實際顯示檢查。

**會把影片上傳到 GitHub 嗎？**

不會。本 repository 只有技能與教學。你的影片留在自己的工作環境；若使用雲端模型或圖片服務，素材處理取決於該工具，這不是純離線保證。

**會自動替我出 Trial？**

不會。預設交付匯出檔、封面和 Caption。發佈需另行指示。

**遇到工具失敗怎麼辦？**

先要求 Agent 說明實際卡在哪一步、已完成哪些產物。提 Issue 時提供版本與可重現步驟，避免公開影片、帳戶資料、密鑰和個人路徑。
