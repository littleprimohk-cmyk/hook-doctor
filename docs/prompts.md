# 可直接複製的指令

把專案名稱換成自己的，並附上影片。

## 完整診斷與製作

```text
使用 $hook-doctor，分析這條 Reel 頭五秒，
在 CapCut 專案「我的影片」建立改善版並完成修改。
沿用我原有字型、配色和 B-roll。
製作符合新開場的封面＋Caption，檢查安全區後匯出。
```

## 只做完整分析

```text
使用 $hook-doctor，只做完整 13 部分分析。
給我整體分數和 6 個子分數、逐秒觀察、一個最大問題，
以及可交給剪片師的 0–3 秒方案和 5 個不同方向 Hook。
暫時不要修改專案。
```

## 先看方案再剪

```text
使用 $hook-doctor，先分析並提出一個可用現有素材完成的剪法。
把每段原片時間、畫面、口播、字幕寫清楚。
等我批准方案後，才去 CapCut 修改。
```

## Trial 第二版

```text
使用 $hook-doctor，以最新的人手修改版本為準。
在 CapCut 建立獨立 Trial 第二版，優先改善頭五秒。
保留原版，做另一張實景封面及 Caption。
字幕和 Caption 用台式繁體書面語，不要替我發佈。
```

## 修正遮擋

```text
使用 $hook-doctor，直接去 CapCut 修正字幕與圖卡遮擋。
修改原有圖層的位置、大小或時長，不要用色塊蓋住原片。
保留重要人臉、手勢、產品和數據，檢查動畫放大後仍在安全區。
```

## English

```text
Use $hook-doctor to audit the first five seconds of this Reel.
Create a separate improved version in my CapCut project "My Reel",
keep my existing visual style and B-roll, and deliver an export,
a safe-zone cover using the real scene, and a ready-to-post caption.
Do not publish it.
```
